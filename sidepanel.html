🌊 Google Flow

memeriksa…
  1. Buka Flow, masuk ke sebuah project.
  2. Tidak perlu atur apa-apa: Klipin otomatis mematikan mode Agen, memilih Gambar, rasio proyek, dan x1 (1 gambar per prompt — paling cepat).
  3. Klik Kirim Semua ke Flow, lalu biarkan berjalan sendiri.

Tip: tarik beberapa gambar sekaligus ke grid di atas untuk mengisi scene kosong secara berurutan.

Cara pasang (sekali saja)

Claude Desktop (paling mudah):

  1. Download klipin.mcpb dari halaman Releases Klipin di GitHub.
  2. Klik dua kali file itu → Claude Desktop terbuka → klik Install.

Claude Code / Cursor / lainnya: buka folder mcp di folder Klipin, lalu klik dua kali Pasang-Klipin-MCP (.command di Mac, .bat di Windows).

Setelah itu, biarkan Chrome terbuka dengan panel Klipin, lalu minta agent-mu:
"Pakai Klipin, buatkan video 3 menit tentang budidaya lele untuk pemula."

Agent hanya bisa terhubung dari komputer ini (localhost). API key tidak pernah dikirim ke agent.
